## 语法讲解

> 按真题出现频次排列。每条含：**核心义、接续、例句、辨析表、真题提示**。

### 〜に対して／につれて（真题 **20** 次 · 2015.12、2016.07、2017.07、2017.12、2018.12、2019.07、2022.07、2023.12、2024.07、2024.12、2025.07、2025.12）

**核心义**
- **に対して（は）**：① 对……（对象）；② 与……相比（对照）
- **につれて**：随着……而……（**同一主体随时间/程度变化**）

**接续**
- 名＋に対して（は）
- 名／动词辞书形＋につれ（て）

**用法详解**
- 「若者**に対して**厳しい」：对年轻人严格
- 「兄**に対して**弟は」：与哥哥相比弟弟……
- 「年を取る**につれて**」：随着年龄增长
- 「値段が上がる**につれて**需要が減る」

**例句**
1. 若い人**に対して**厳しすぎる。
2. 試験が近づく**につれて**、不安が増した。
3. 子供**に対して**ではなく、大人**向け**の本。

**近义辨析**
| | に対して | について | につれて |
|---|----------|----------|----------|
| 对象 | 对人/对照 | 关于话题 | 随时间变化 |
| 时间 | ✗ | ✗ | ✓ |

**真题提示**：句中有 **两个比较对象** → に対して；**同一事物渐变** → につれて。N2 最高频语法点之一（20次）。

### 敬语（真题 **16** 次 · 2015.07、2015.12、2016.07、2017.07、2017.12、2018.07、2018.12、2019.12、2021.07、2021.12、2022.07、2024.12、2025.07）

**核心义**：N2 敬语题考 **尊敬语**（抬高对方）、**自谦语**（降低自己）、**礼貌语** 的正确搭配与方向。

**三大类型速查**

| 类型 | 作用 | 常见表达 |
|------|------|----------|
| 尊敬语 | 抬高对方动作 | お越しになる、いらっしゃる、おっしゃる、なさる、ご覧になる |
| 自谦语 | 降低己方动作 | 参る、伺う、申し上げる、差し上げる、いただく |
| 郑重/礼貌 | 对顾客、正式场合 | うけたまわる、申し上げる、ございます |

**方向记忆（必考）**
- 己方对客户/上级：**申し上げる**（说）、**差し上げる**（给）、**伺う**（问/拜访）
- 客户对己方：**お越しください**、**うけたまわります**（承蒙/受理）
- × 对上级用 **差し上げる** 陈述自己服务 ✓；× 自己用 **おっしゃる** ✗

**例句（2015.07 第38题场景：花屋主页）**
- 送料無料で日にち指定の全国発送も（ **うけたまわります** ）。
- ご予約**申し上げます**／**いただきます**（收到预约）

**真题陷阱**
- **いただく** vs **差し上げる**：谁给谁
- **申し上げる** vs **おっしゃる**：谁说
- 商家用语 **うけたまわる** = 承蒙订购、受理服务

**做题步骤**：① 确定主语（我方/对方）② 确定动作方向（给予/接受/报告）③ 选对应敬语动词。

### 让步（真题 **11** 次 · 2015.12、2016.07、2017.07、2017.12、2019.12、2020.12、2021.07、2022.07、2023.12、2024.07）

**核心义**：**即使……也……** 或 **就……来说**（与预期不符）。

**主要句型**

| 句型 | 义 | 例 |
|------|-----|-----|
| **にしては** | 就……而言（超出/不及预期） | 子供**にしては**上手 |
| **にしても／としても** | 即使……也 | 雨**にしても**行く |
| **たとえ〜ても** | 即使……也 | **たとえ**遠く**離れても** |
| **としては** | 作为……来说 | 教師**としては** |

**用法详解**
- **にしては**：评价超出身份/年龄的预期；「子供**にしては**大人しい」
- **たとえ〜ても**：经典让步；「**たとえ**失敗**しても**諦めない」
- **にしても** vs **としても**：前者偏「就算A也B」；后者可表身份立场

**例句**
1. 初心者**にしては**よくできた。
2. **たとえ**反対**されても**、言うべきことは言う。
3. 忙しい**にしても**、連絡ぐらいしてほしい。

**真题提示（2017.07 第35题）**：`たとえ遠く（ ）、友情は変わらない` → **離れても**（たとえ…ても 固定让步）。

### 〜ことになる／ことに（真题 **10** 次 · 2015.12、2018.07、2018.12、2019.12、2021.07、2024.07、2025.07、2025.12）

**核心义**
- **ことになる**：（客观）决定/结果是……；规定为……
- **ことに**：令人……的是（接イ形/ナ形，表说话人感受）

**接续**
- 动词辞书形＋**ことになる**
- イ形/ナ形＋**ことに**

**用法详解**
- 「ことになる」：公司规定、社会惯例、自然结果；主语常非人
- 「ことになっている」：规定好了
- 「驚いた**ことに**」「幸い**なことに**」「残念**なことに**」

**例句**
1. 来月引っ越す**ことになった**。
2. 会議は中止**になる**。
3. **幸いなことに**、怪我はなかった。

**近义辨析**
| | ことになる | ことにする | ことになっている |
|---|------------|------------|------------------|
| 谁决定 | 客观/外界 | 主观决定 | 规定/惯例 |

**真题提示**：看到 **驚いた／残念／幸い** → ことに；看到 **决定/规定/结果是** → ことになる。

### 副词（真题 **10** 次 · 2018.07、2018.12、2019.07、2019.12、2021.07、2021.12、2024.07、2024.12、2025.07）

**核心义**：N2 真题常单独考副词辨析，以下为高频项：

| 副词 | 义 | 例句 |
|------|-----|------|
| **いったい** | 到底、究竟 | **いったい**何が問題だ |
| **つい** | 不由得、无意中 | **つい**食べ過ぎた |
| **いつのまにか** | 不知不觉 | **いつのまにか**春になった |
| **まもなく** | 不久、眼看就要 | **まもなく**出発します |
| **かえって** | 反而 | 説明した**かえって**混乱した |
| **どうしても** | 务必/怎么也 | **どうしても**行きたい |
| **おそらく** | 恐怕、大概 | **おそらく**雨だろう |
| **一気に** | 一口气（单人） | **一気に**食べた |
| **一斉に** | 一齐（多人） | 皆**一斉に**立った |

**近义辨析**
- **一気に** vs **一斉に**：是否「みんな/皆」
- **いったい** vs **どうしても**：疑问 vs 意志
- **つい** vs **いつのまにか**：主观失手 vs 时间 unnoticed

**真题提示**：填空四选项全是副词时，看 **前后句逻辑**（转折→かえって；疑问→いったい；时间→まもなく/いつのまにか）。

### 〜だけ／きり／抜き（真题 **9** 次 · 2016.07、2018.07、2019.07、2020.12、2022.07、2024.07、2025.12）

**核心义**（三个限定表达，真题常混考）
- **だけ**：只、仅；**だけの**＋名：仅仅…的
- **きり／っきり**：自从…就再没…；只有…
- **抜き（で）**：去掉…、不用…、省略…

**接续**
- 名＋だけ（の）
- 名＋きり（っきり）
- 名＋抜き（で）

**用法详解**
- `朝食抜きで`：没吃早饭（省略某环节）
- `東京きり`：自从去了东京就……
- `見るだけのつもりで`：本打算只看看 → 常与「つい…てしまう」语序题联动
- `だけでなく`：不仅…而且…

**例句**
1. 今朝は寝坊して、朝食**抜きで**大学に来た。
2. 彼女に会った**きり**、連絡がない。
3. ちょっと**見るだけの**つもりで入った店で、つい買ってしまった。

**真题提示**：看到 **抜き／きり／だけ** 同时出现，抓句子语义：「不做某事」→抜き；「自从…后没再」→きり；「只/本打算只」→だけ。

### 目的・原因（真题 **9** 次 · 2017.12、2019.07、2021.07、2021.12、2023.12、2024.12）

**核心义**：表 **目的**、**原因/理由**、**结果归因** 的多种表达，N2 极高频混考。

**主要句型**

| 句型 | 义 | 接续 |
|------|-----|------|
| **ように** | 为了…（目的） | 动词辞书形/ない形＋ように |
| **ために** | 为了…/因为… | 名のために；动词辞书形＋ために |
| **おかげで** | 多亏…（好结果） | 原因＋おかげで |
| **せいで** | 都怪…（坏结果） | 原因＋せいで |
| **から／ので** | 因为… | 普通形＋から/ので |

**用法详解**
- `分かる**ように**説明する`：为了让人懂
- `雨**のせいで**試合中止`：都怪雨
- `先生**のおかげで**合格`：多亏了老师
- ために：名词/动词都可；**ために** 可表目的也可表原因，看上下文

**例句**
1. 健康**のために**運動している。（目的）
2. 事故**のせいで**電車が遅れた。（原因·负面）
3. 聞こえる**ように**大きな声で話した。

**真题提示**：**好结果** → おかげで；**坏结果** → せいで；**目的** → ように／ために；后接「说明/努力」→ ように。

### 补助动词（真题 **9** 次 · 2017.12、2018.07、2018.12、2020.12、2023.12、2024.07、2025.07）

**核心义**：接在 **て形** 后，补充动作的方式、意图、结果等。N2 常考：

| 补助 | 义 | 例 |
|------|-----|-----|
| **てみる** | 试着做 | 食べ**てみる** |
| **てしまう** | 做完/ unfortunately | 忘れ**てしまった** |
| **ておく** | 预先做好 | 予約し**ておく** |
| **てくる** | 开始做/来到现在 | 雨が降っ**てきた** |
| **ていく** | 继续/向未来 | これからも頑張っ**ていく** |
| **つもり（で）** | 打算/本以为 | 見る**つもりで** |
| **てほしい** | 希望别人做 | 来**てほしい** |
| **てあげる/もらう/くれる** | 授受 | 教え**てあげる** |

**语序题高频**：`ちょっと **見るつもりで** 服屋に入ったら、つい買ってしまった`

**真题提示**
- 「本打算只…却…」→ **つもりで** + **てしまう**
- 「希望对方…」→ **てほしい**（注意主语）
- 「预先…」→ **ておく**

### 〜ばかり（真题 **8** 次 · 2015.07、2016.07、2017.07、2018.12、2020.12、2024.07、2024.12）

**核心义**（多义，需看上下文）
1. **只、仅**（≈だけ，但语气稍重）
2. **几乎全是**（后面接名词）
3. **越来越…**（形容词/形容动词词干＋**ばかりだ**／**ばかり**）

**接续**
- 名詞＋ばかり
- 动词て形＋ばかり（いる）
- イ形/ナ形词干＋ばかり（だ）

**用法详解**
- `むしろ〜ばかり`：非但没有好转，反而越来越……（2015.07 第35题经典）
- `〜たばかり`：刚……（时间点，与「ばかりだ」趋势义不同）
- `〜ばかりか`：不仅……而且……

**例句**
1. 雨はやまず、むしろ**強くなるばかり**だった。
2. 彼女は文句**ばかり**言っている。
3. 日本**に来たばかり**で、まだ慣れない。

**近义辨析**
| | ばかり | だけ |
|---|--------|------|
| 只/仅 | ✓ | ✓ |
| 越来越 | ばかりだ | ✗ |
| 刚… | たばかり | たところ |

**真题提示**：题干有 **むしろ／一方で** → 倾向「越来越」；选项为形容词四种形态 → 选 **词干+ばかり** 或 **ばかりだ**。

### 引用・是否（真题 **8** 次 · 2017.12、2018.07、2018.12、2021.12、2023.12、2024.12、2025.07）

**核心义**：引用、定义、是否判断。

**主要句型**
- **かどうか**：是否……（行く**かどうか**）
- **というと／といえば**：说到……；如果说是……
- **というのは**：所谓……是（定义）
- **というより**：与其说……不如说……
- **とは限らない**：不一定……

**例句**
1. 参加する**かどうか**まだ決めていない。
2. 日本**というと**、桜を思い浮かべる。
3. 彼**といえば**、昨日会ったばかりだ。

**真题提示**：`〜かどうか` 后接 **わからない／決めていない**；`というと` 后接 **典型联想**。

### 条件・义务（真题 **6** 次 · 2015.07、2020.12、2021.07、2022.07、2024.12）

**核心义**：条件、义务、禁止。

**主要句型**
| 句型 | 义 |
|------|-----|
| **なければならない** | 必须 |
| **なくてはいけない/ならない** | 必须（口语） |
| **ないと** | 必须/否则（口语） |
| **てはいけない** | 不许 |
| **てからでないと** | 必须先…才能… |
| **以上（は）** | 既然…就… |
| **べきだ** | 应该（道义） |

**例句**
1. 規則を守ら**なければならない**。
2. 約束した**以上は**守るべきだ。
3. ここでタバコを吸っ**てはいけない**。

**真题提示**：「必须做」→ なければならない；「既然…就…」→ 以上は；「禁止」→ てはいけない。

### 数量＋に（达到）（真题 **4** 次 · 2015.07、2015.12、2024.07、2025.12）

**核心义**：数量词后接助词 **に**，表示数量「达到」某一水平，与移动、达成类动词搭配。

**接续**：数量词（数字+量词）＋ **に** ＋ 上る／達する／及ぶ 等

**用法详解**
- 「に上る」= 达到（人数、金额、规模），书面、新闻常见
- 「に達する」= 达到（标准、数值）
- 助词对比：**で**=方式/原因；**を**=宾语；**も**=「也/竟有」强调数量之多

**例句**
1. 入場者数は1000万人**に上った**。（入场人数达到了1000万）
2. 売上高が昨年**に達した**。（销售额达到了去年水平）
3. 被害者は100人**を超えた**。（受害者超过了100人）← 超える前用「を」

**近义辨析**
| 助词 | 功能 | 典型动词 |
|------|------|----------|
| に | 达到某数量点 | 上る、達する |
| を | 越过/超过 | 超える |
| で | 方式、原因 | — |

**真题提示（2015.07 第33题）**：`1000万人（ ）上った` → 选 **に**。看到「数字+上る/達する」几乎固定 **に**。

### 〜もの（真题 **4** 次 · 2016.07、2017.07、2020.12、2023.12）

**核心义**：形式名词「もの」，N2 常考四种固定句型，**必须按后接形式区分**。

**主要句型**

| 句型 | 义 | 接续 |
|------|-----|------|
| **ものだ** | 一般性道理、感慨 | 普通形＋ものだ |
| **ものではない** | 不应该（规劝） | 辞书形＋ものではない |
| **ものの** | 虽然……但是…… | 普通形＋ものの |
| **ものなら** | 如果可能的话…… | 辞书形＋ものなら |

**用法详解**
- **ものだ**：「子供は元気な**ものだ**」= 孩子嘛，就是活泼（说话人感慨、一般真理）
- **ものではない**：「約束を破る**ものではない**」= 不该违约（社会规范）
- **ものの**：前项成立，后项却未如愿；比「のに」稍书面
- **ものなら**：与「〜たい」连用，表「要是能……就好了（但做不到）」

**例句**
1. 人生は思い通りにならない**ものだ**。
2. 人の悪口を言う**ものではない**。
3. 行きたい**ものの**、時間がなくて行けなかった。
4. 行ける**ものなら**、今すぐ行きたい。

**近义辨析**
| | ものだ | はずだ | べきだ |
|---|--------|--------|--------|
| 类型 | 感慨/常理 | 理应如此 | 应该做 |

**真题提示**：选项四者齐出（ものだ／ものではない／ものの／ものなら）时，看 **后项语气**：规劝→ではない；转折→ものの；假设→なら。

### 假设（真题 **4** 次 · 2017.07、2017.12、2019.07）

**核心义**：提出 **假设条件**，后项多为判断、建议、结果。

**主要句型**
- **とすると／としたら／とすれば**：假如……的话（较书面）
- **なら／ならば**：如果是……（口语、针对具体对象）
- **ものなら**：如果可能的话（与愿望连用）

**接续**
- 普通形＋**とすると** 等
- 名詞／普通形＋**なら**

**用法详解**
- 「彼**なら**分かる」：如果是他，能懂（针对「彼」）
- 「雨**としたら**、中止だ」：假如下雨就取消
- 「行ける**ものなら**行きたい」：能去的话想去（实际去不了）

**例句**
1. あなた**なら**、どうしますか。
2. 100万円**としたら**、何に使う？
3. 時間がある**ものなら**、手伝いたい。

**近义辨析**
| | としたら | なら | ものなら |
|---|----------|------|----------|
| 假设 | 一般条件 | 针对该对象 | 与愿望/可能 |

**真题提示**：`たとえ遠く（ ）` → **離れても**（即使类让步，见 **让步** 条）；纯假设问「假如…怎么办」→ **としたら**。

### 看法・变化（真题 **4** 次 · 2017.12、2018.07、2019.12、2025.07）

**核心义**：表 **能力·习惯的变化** 或 **主观努力** 或 **外观判断**。

**主要句型**
| 句型 | 义 | 接续 |
|------|-----|------|
| **ようになる** | 变得能/会……（自然变化） | 辞书形/ない形＋ように |
| **ようにする** | 设法做到……（主观努力） | 辞书形/ない形＋ように |
| **ように見える** | 看起来…… | 普通形＋ように見える |
| **ように思える** | 觉得好像…… | 普通形＋ように思える |

**用法详解**
- **ようになる**：能力、习惯从不→有；「日本語が話せる**ようになった**」
- **ようにする**：每天刻意做；「忘れない**ようにしている**」
- **ように見える**：外观印象；「幸せ**に見える**」

**例句**
1. 毎日練習して、泳げる**ようになった**。
2. 遅刻しない**ようにしている**。
3. 子供**のように見える**が、実は30歳だ。

**近义辨析**
| | ようになる | ようにする |
|---|------------|------------|
| 主语 | 自然变化 | 人为努力 |

**真题提示**：题干有 **练习/每天/努力** → ようにする；**结果已经会了** → ようになる。

### 〜がち／づらい 等（真题 **4** 次 · 2018.07、2021.07、2022.07、2023.12）

**核心义**：表 **倾向** 或 **难易度**，N2 常把四个后缀放一起考。

**主要表达**

| 表达 | 义 | 接续 | 主语 |
|------|-----|------|------|
| **がち** | 有……倾向 | 名詞＋がち | 第三人称 |
| **づらい／にくい** | 难以（主观） | 动词词干＋づらい | 说话人 |
| **がたい** | 难以（书面） | 动词词干＋がたい | — |
| **気味** | 有点……倾向 | 名詞＋気味 | — |

**用法详解**
- **がち**：「最近、病気**がち**だ」= 最近老生病
- **言いづらい**：不好意思说（主观感受）

### 接续・逆接（真题 **4** 次 · 2021.07、2022.07、2025.07）

**核心义**：**逆接、转折、对比**，N2 常考带感情色彩的表达。

**主要句型**

| 句型 | 义 | 语气 |
|------|-----|------|
| **のに** | 虽然……却…… | 意外、不满 |
| **くせに** | 明明……却…… | **责备** |
| **ながらも** | 虽然……也…… | 承认后转折 |
| **どころか** | 别说……连…… | 递进否定 |
| **わりに** | 与……不符 | 评价反差 |
| **からには** | 既然……就…… | 决心 |

**例句**
1. 約束した**のに**来ない。
2. 知らない**くせに**偉そうだ。
3. 子供**ながらも**我慢した。
4. 暇**どころか**忙しい。

**真题提示**：带 **责备** → くせに；**前后属性反差**（小却成熟）→ にしては 或 わりに；**不仅不…反而** → どころか。

### てからでないと（真题 **3** 次 · 2015.12、2019.07、2024.12）

**核心义**：必须……之后才能……；不先完成前项，后项不能成立（**强先后顺序条件**）。

**接续**：动词**て形**＋**からでないと**（＋动词ない形／受身形）

**用法详解**
- 强调 **B 以 A 完成为前提**
- 与「てからで（なくて）」：后者是「不…而…」逆接，不是条件
- 与「てから」单纯时间先后不同：「てからでないと」含**许可/可能条件**

**例句**
1. 哲学Ⅰの単位を取得**してからでないと**、哲学Ⅱは受けられない。
2. 親の許可を得**てからでないと**、留学できない。
3. × 食事**をしてからで**、散歩に行った。（正确：食事をしてから）

**近义辨析**
| 表达 | 义 |
|------|-----|
| てからでないと | 不先A就不能B |
| なければならない | 必须做 |
| てはいけない | 禁止做 |

**真题提示（2015.07 第36题）**：`取得（ ）、受けられない` → **してからでないと**。

### 〜かのようだ（真题 **3** 次 · 2015.12、2017.07、2025.07）

**核心义**：**好像……似的**（说话人主观比喻、强调「简直像」）。

**接续**：普通形＋**かのようだ**（常配合 **まるで**）

**用法详解**
- 与 **らしい** 不同：らしい = 有根据的典型特征/传闻；かのよう = 主观感觉像
- 与 **みたい** 不同：みたい 口语；かのよう 书面
- 常接 **まるで＋名词＋かのようだ**

**例句**
1. **まるで**夢**かのようだった**。
2. 知らない人**かのように**振る舞った。
3. **まるで**時間が止まった**かのよう**だ。

**近义辨析**
| | かのようだ | らしい | みたい |
|---|------------|--------|--------|
| 依据 | 主观比喻 | 典型/传闻 | 口语比喻 |

**真题提示**：题干有 **まるで** → 优先 **かのよう**；表「听说/典型」→ らしい。

### 〜しかない／ほかない（真题 **3** 次 · 2016.07、2018.12、2025.07）

**核心义**：**只好、只能**（别无他法）；**ほかない** 书面/强调「只有这一条路」

**接续**：动词辞书形 **しかない**；名词 **からしか**／**にしか**＋否定

**用法详解**
- **2種類からしか選べない**：只能从两种里选（2018.07 类题）
- **歩くしかない**：只能走
- 与 **わけにはいかない**（不能）语义 **相反**

**例句**
1. バスがないから、歩いて行く**しかない**。
2. こうする**ほかない**。
3. AかBの2種類**からしか**選べない。

**辨析**
| 表达 | 义 |
|------|-----|
| **しかない** | 只能（口语多） |
| **ほかない** | 别无他法（稍书面） |
| **からしか** | 只能从…… |
| **わけにはいかない** | **不能**做 |

**真题提示**：满员电车「只能挤上去」→ **しかない**；「不能休息」→ **わけにはいかない**（勿混）。

### わけにはいかない（真题 **3** 次 · 2018.07、2021.07、2025.12）

**核心义**：**情理上不能、处境上不允许**（想做或觉得应该做，但没法做）。

**接续**：动词**辞书形**＋**わけにはいかない**

**用法详解**
- 比「てはいけない」（禁止）语气软：不是规定禁止，是**面子/责任/处境**不允许
- 与「休んでもおかしくない」（不奇怪）构成对立选项
- 「わけがない」= 不可能；「わけではない」= 并非

**例句**
1. 熱があるが、大事な会議があるので休む**わけにはいかない**。
2. 嘘をつく**わけにはいかない**。
3. 行きたいが、お金がなくて行く**わけにはいかない**。

**近义辨析（2015.07 第39题四选项）**
| 选项 | 义 |
|------|-----|
| 休んでもおかしくない | 休息也不奇怪（可以休） |
| 休みっこない | 没法休息（口语） |
| **休むわけにはいかない** | **不能休（情理）** |
| 休むほかない | 只能休 |

**真题提示**：对话中对方说「有热/有重要会议」→ 不能休息 → **わけにはいかない**。

### 〜ほどだ（真题 **3** 次 · 2018.12、2021.12、2025.07）

**核心义**（两义，看接续）

**① 程度**：……得…… / 到了……地步
- イ形/ナ形＋**ほどだ**；动词普通形＋**ほどだ**
- 「忙しい**ほどだ**」= 忙得要命

**② 一方だ**：越来越……（状态 **单向变化**）
- イ形/ナ形词干＋**一方だ**
- 「物価は上がる**一方だ**」= 物价一直在涨

**例句**
1. 痛い**ほどだ**。
2. 待ちたくない**ほど**混んでいる。
3. 人口は減少する**一方だ**。

**近义辨析**
| | ほどだ | ばかりだ | 一方だ |
|---|--------|----------|--------|
| 程度 | ✓ | 越来越 | 越来越（状态） |

**真题提示**：经济/社会 **持续恶化/增长** → **一方だ**；强调 **程度之深** → **ほどだ**。

**用法详解**
- 比「ときに」正式；常用于 **演讲、仪式、项目启动**

**例句**

### 〜うちに（真题 **3** 次 · 2020.12、2025.07、2025.12）

**核心义**：**在……期间**（发生某种变化）；或 **趁着还没……**

**接续**
- 动词辞书形/ている/ない＋**うちに**
- イ形/ナ形＋**うちに**

**用法详解**
- 变化义：「知らない**うちに**春になった」= 不知不觉春天了
- 趁着义：「若い**うちに**勉強しなさい」= 趁年轻学习

|---|--------|------|--------|

**真题提示**：「还没……就……了」→ **ないうちに**；「一没货就结束」→ **なくなり次第**。

### をめぐる／の末（真题 **3** 次 · 2021.12、2023.12、2025.12）

**核心义**
- **をめぐって／をめぐり**：围绕……（话题、争议、讨论）
- **の末（に）**：经过（长期努力、讨论、斗争）之后，终于……

**接续**
- 名詞＋をめぐって（をめぐり）
- 名詞＋の末（に）

**用法详解**
- 「をめぐって」后接：議論する、争う、意見が分かれる、話し合い
- 「の末に」前接：長期間の〜、苦労の〜、議論の〜；后接：決定した、結論が出た

**例句**

**近义辨析**
| 表达 | 关键词 | 后项 |
|------|--------|------|
| をめぐって | 围绕、关于 | 讨论/对立 |
| の末に | 经过…之后 | 决定/结果 |
| を込めて | 带着…心情 | 动作 |

**真题提示**：选项常四者齐出（をめぐり／を込めて／の末に／のことで）。**议论+最终决定** → の末に；**围绕某议题** → をめぐって。

### 〜とおり／まま（真题 **2** 次 · 2017.07、2017.12）

**真题提示（2017.07 第36题）**：祖母担心留学中的我 → **心配でならない**（固定：担心得不得了）；「正如所说」→ **とおり**。

### 双重否定・抑制（真题 **2** 次 · 2017.07、2018.07）

**核心义**：双重否定表 **委婉肯定** 或 **抑制不住** 或 **不得不**。

**主要句型**

| 句型 | 义 |
|------|-----|
| **ないことはない** | 并非不……（委婉肯定） |
| **ずにはいられない** | 忍不住…… |
| **ないわけにはいかない** | 不得不…… |
| **ないではいられない** | 同「ずにはいられない」 |

**例句**
1. 行け**ないことはない**が、時間がない。（不是不能去，但……）
2. 笑わ**ずにはいられない**。
3. 謝ら**ないわけにはいかない**。

**近义辨析**
| | ないことはない | ないわけにはいかない |
|---|----------------|----------------------|
| 义 | 并非不能（弱肯定） | 必须做（被迫） |

**真题提示**：「并非完全不行，但……」→ ないことはない；「情面上不得不」→ ないわけにはいかない。

### 比较表达（真题 **2** 次 · 2018.12、2022.07）

**核心义**：**比较级、最高级、比例** 相关表达。

**主要句型**
- **より（も）**：比……更
- **ほうが**：……更……
- **いちばん**：最……
- **のわりに**：与……不符（见 **让步**）
- **に比べて**：与……相比

**例句**
1. 昨日**より**寒い。
2. コーヒー**のほうが**好きだ。
3. 今まで乗った中で**いちばん**小さかった。
4. 値段**のわりに**質がいい。

**真题提示（2018.12 第39题）**：`どの（ ）小さかった` → **飛行機がいちばん**（最高级）；「与价格不符的好」→ **わりに**。

### 固定表达（真题 **2** 次 · 2019.12、2024.07）

### 〜のに（真题 **2** 次 · 2019.12、2021.12）

**接续**：动词/い形/な形 **のに**；名词 **なのに**

**例句**
1. 約束した**のに**、来なかった。（说了却不来）
2. 子供**なのに**、大人みたいだ。
3. 雨**なのに**、出かけた。

**辨析**
| 表达 | 语气 |
|------|------|
| **のに** | 一般逆接、意外 |
| **くせに** | 责备「明明…却…」 |
| **ながらも** | 承认后转折 |

**真题提示**：前句表预期/条件，后句表 **相反结果** → のに；带责备 → くせに。

### 〜に違いない 等（真题 **2** 次 · 2019.12、2022.07）

### 语境型（真题 **2** 次 · 2025.12）

### 〜をめぐって（真题 **1** 次 · 2015.07）

**核心义**
- **をめぐって／をめぐり**：围绕……（话题、争议、讨论）
- **の末（に）**：经过（长期努力、讨论、斗争）之后，终于……

**接续**
- 名詞＋をめぐって（をめぐり）
- 名詞＋の末（に）

**用法详解**
- 「をめぐって」后接：議論する、争う、意見が分かれる、話し合い
- 「の末に」前接：長期間の〜、苦労の〜、議論の〜；后接：決定した、結論が出た
- **を込めて**：带着（心情）做……——强调「心意」，不是「经过过程」

**例句**
1. 新駅建設**をめぐって**、住民と鉄道会社が対立している。
2. 長期間の議論**の末に**、計画が承認された。
3. 祈り**を込めて**花を供えた。

**近义辨析**
| 表达 | 关键词 | 后项 |
|------|--------|------|
| をめぐって | 围绕、关于 | 讨论/对立 |
| の末に | 经过…之后 | 决定/结果 |
| を込めて | 带着…心情 | 动作 |

**真题提示**：选项常四者齐出（をめぐり／を込めて／の末に／のことで）。**议论+最终决定** → の末に；**围绕某议题** → をめぐって。

### 〜次第（一…就）（真题 **1** 次 · 2015.07）

**核心义**
1. **一…就…**（前项发生，后项**立即**跟进）——动词辞书形＋次第
2. **取决于、由…决定**（次第で／次第だ）——与「一…就」义不同，看语境

**接续**
- 动词**辞书形**＋次第（だ）
- 名词＋次第（だ）

**用法详解**
- `なくなり次第`：一没货/一卖完就……（2015.07 第37题）
- `次第に`：逐渐（副词，≠ 一…就）
- `次第で`：看情况、取决于

**例句**
1. 商品が**なくなり次第**、セールを終了します。
2. 内容**次第で**、引き受けるか決めます。
3. 雨が**止み次第**、出発しましょう。

**近义辨析**
| | 次第 | うちに | 以上 |
|---|------|--------|------|
| 一…就 | ✓（辞书形+次第） | ✗ | ✗ |
| 在…期间 | ✗ | ✓ | ✗ |
| 既然 | ✗ | ✗ | ✓ |

**真题提示**：`商品が（ ）終了` → **なくなり次第**；若后项是「决定/看情况」→ 次第で。

### か何か／や何か（真题 **1** 次 · 2015.07）

**核心义**：……之类的；或什么的（**不确定的举例**）。

**接续**
- 名詞＋**か何か**
- 名詞＋**や何か**（で／か）

**用法详解**
- 「か何か」：某一类事物中的「什么」（杂志啊什么的）
- 「や何かで」：通过……等方式（2015.07 第40题：雑誌**や何かで**取り上げられている）
- 「か何かを」：吃/买……之类的

**例句**
1. 雑誌**か何か**でこの店を知った。
2. お茶**でも**何か**いかがですか**。
3. テレビ**や何かで**流れた。

**真题提示**：`雑誌（ ）よく取り上げられて` → **か何か**／**や何かで**；后接「で取り上げる」→ **や何かで** 更自然。

### 〜くらい（真题 **1** 次 · 2015.12）

**核心义**：表 **程度** 或 **最低限度**（口语 **ぐらい**）。

**主要用法**
1. **程度**：忙しい**くらい**（忙得要命）≈ ほど
2. **最低限度**：これ**くらい**（至少这个）／**くらい**しかない
3. **语序题高频**：初対面**とは思えない**＋**くらい**＋……

**接续**：普通形＋**くらい**；数量＋**くらい**

**例句**
1. 死ぬ**くらい**疲れた。
2. これ**くらい**の問題ならできる。
3. 驚く**くらい**上手だ。

**近义辨析**
| | くらい | ほど | ばかり |
|---|--------|------|--------|
| 程度 | ✓（口语） | ✓（书面） | 越来越 |

**真题提示**：语序题「不像初次见面 **到那种程度**」→ **くらい**；「至少」→ **くらい** 表最低标准。

### 口语・否定（真题 **1** 次 · 2016.07）

**主要句型**

### 义务・许可（真题 **1** 次 · 2019.12）

**核心义**：**允许做** vs **必须做** vs **不奇怪/没关系**。

**主要句型**
- **てもいい**：可以……（许可）
- **てもかまわない／てもおかしくない**：……也没关系/不奇怪
- **なくてはいけない**：必须
- **てはいけない**：不许

**例句**
1. ここで写真を撮っ**てもいい**ですか。
2. 休ん**でもおかしくない**。（休息也不奇怪）

- **を契機に（して）**：以……为转机（书面）

### 〜ずに済む（真题 **1** 次 · 2024.07）

### 〜ように（目的）（真题 **1** 次 · 2025.12）

**核心义**：表 **目的**、**原因/理由**、**结果归因** 的多种表达，N2 极高频混考。

**主要句型**

| 句型 | 义 | 接续 |
|------|-----|------|
| **ように** | 为了…（目的） | 动词辞书形/ない形＋ように |
| **ために** | 为了…/因为… | 名のために；动词辞书形＋ために |
| **おかげで** | 多亏…（好结果） | 原因＋おかげで |
| **せいで** | 都怪…（坏结果） | 原因＋せいで |
| **から／ので** | 因为… | 普通形＋から/ので |

**用法详解**
- `分かる**ように**説明する`：为了让人懂
- `雨**のせいで**試合中止`：都怪雨
- `先生**のおかげで**合格`：多亏了老师
- ために：名词/动词都可；**ために** 可表目的也可表原因，看上下文

**例句**
1. 健康**のために**運動している。（目的）
2. 事故**のせいで**電車が遅れた。（原因·负面）
3. 聞こえる**ように**大きな声で話した。

**真题提示**：**好结果** → おかげで；**坏结果** → せいで；**目的** → ように／ために；后接「说明/努力」→ ように。

**33** [填空] **数量＋に（达到）**
- **要点**：数量词后接助词 **に**，表示数量「达到」某一水平，与移动、达成类动词搭配。
- **题干**：Y遊園地の昨年の入場者数は、1000万人（ ）上った。
- **选项**：1.に　2.で　3.を　4.も
- **例句**：入場者数は1000万人**に上った**。（入场人数达到了1000万）
- **做题**：真题提示（2015.07 第33题）：`1000万人（ ）上った` → 选 に。看到「数字+上る/達する」几乎固定 に。

**34** [填空] **〜をめぐって**
- **要点**：
- **题干**：鉄道会社と自治体による長期間の議論（ ）、新駅の建設が決定された。
- **选项**：1.をめぐり　2.を込めて　3.の末に　4.のことで
