## 语法讲解

> 按真题出现频次排列。每条含：**核心义、接续、例句、辨析表、真题提示**。

### ★语序题（真题 **90** 次 · 2015.07、2015.12、2016.07、2017.07、2017.12、2018.07、2018.12、2019.07、2019.12、2020.12、2021.07、2021.12、2022.07、2023.12、2024.07、2024.12、2025.07、2025.12）

**核心义**：将 1·2·3·4 四个片段排成正确句子；**★** 标记的位置 = 正确项应填入的位置。

**解题步骤（必做）**
1. **找固定搭配**：つもりで、のに、ぐらい、ように、からには、てしまう
2. **找主句谓语**：句子核心动词在哪
3. **找修饰关系**：谁修饰谁（名词+の、动词修饰名词）
4. **验证**：读通整句，检查助词

**高频语序模式**
```
ちょっと [見る] [つもりで] [服屋に入ったら]、つい買ってしまった。
そんなに [痛い] [のに] → 早く行けばいい / んだったら
初対面とは思えない [ぐらい] [話が盛り上がった] [のを] [よく覚えている]
```

**真题提示**
- 修饰语在中心语 **前**（日语 SOV）
- 「のを」常接 **remember/feel** 类动词
- 每套 **5 题**，18 套共 90 题；与填空分开复习

### 〜に対して／につれて（真题 **20** 次 · 2015.12、2016.07、2017.07、2017.12、2018.12、2019.07、2022.07、2023.12、2024.07、2024.12、2025.07、2025.12）

**核心义**
- **に対して（は）**：① 对……（对象）；② 与……相比（对照）
- **につれて**：随着……而……（**同一主体随时间/程度变化**）

**接续**
- 名＋に対して（は）
- 名／动词辞书形＋につれ（て）

**用法详解**
- 「若者**に対して**厳しい」：对年轻人严格
- 「兄**に対して**弟は」：与哥哥相比弟弟……
- 「年を取る**につれて**」：随着年龄增长
- 「値段が上がる**につれて**需要が減る」

**例句**
1. 若い人**に対して**厳しすぎる。
2. 試験が近づく**につれて**、不安が増した。
3. 子供**に対して**ではなく、大人**向け**の本。

**近义辨析**
| | に対して | について | につれて |
|---|----------|----------|----------|
| 对象 | 对人/对照 | 关于话题 | 随时间变化 |
| 时间 | ✗ | ✗ | ✓ |

**真题提示**：句中有 **两个比较对象** → に対して；**同一事物渐变** → につれて。N2 最高频语法点之一（20次）。

### 敬语（真题 **15** 次 · 2015.07、2015.12、2016.07、2017.07、2017.12、2018.07、2018.12、2019.12、2021.07、2021.12、2022.07、2024.12、2025.07）

**核心义**：N2 敬语题考 **尊敬语**（抬高对方）、**自谦语**（降低自己）、**礼貌语** 的正确搭配与方向。

**三大类型速查**

| 类型 | 作用 | 常见表达 |
|------|------|----------|
| 尊敬语 | 抬高对方动作 | お越しになる、いらっしゃる、おっしゃる、なさる、ご覧になる |
| 自谦语 | 降低己方动作 | 参る、伺う、申し上げる、差し上げる、いただく |
| 郑重/礼貌 | 对顾客、正式场合 | うけたまわる、申し上げる、ございます |

**方向记忆（必考）**
- 己方对客户/上级：**申し上げる**（说）、**差し上げる**（给）、**伺う**（问/拜访）
- 客户对己方：**お越しください**、**うけたまわります**（承蒙/受理）
- × 对上级用 **差し上げる** 陈述自己服务 ✓；× 自己用 **おっしゃる** ✗

**例句（2015.07 第38题场景：花屋主页）**
- 送料無料で日にち指定の全国発送も（ **うけたまわります** ）。
- ご予約**申し上げます**／**いただきます**（收到预约）

**真题陷阱**
- **いただく** vs **差し上げる**：谁给谁
- **申し上げる** vs **おっしゃる**：谁说
- 商家用语 **うけたまわる** = 承蒙订购、受理服务

**做题步骤**：① 确定主语（我方/对方）② 确定动作方向（给予/接受/报告）③ 选对应敬语动词。

### 〜ことになる／ことに（真题 **10** 次 · 2015.12、2018.07、2018.12、2019.12、2021.07、2024.07、2025.07、2025.12）

**核心义**
- **ことになる**：（客观）决定/结果是……；规定为……
- **ことに**：令人……的是（接イ形/ナ形，表说话人感受）

**接续**
- 动词辞书形＋**ことになる**
- イ形/ナ形＋**ことに**

**用法详解**
- 「ことになる」：公司规定、社会惯例、自然结果；主语常非人
- 「ことになっている」：规定好了
- 「驚いた**ことに**」「幸い**なことに**」「残念**なことに**」

**例句**
1. 来月引っ越す**ことになった**。
2. 会議は中止**になる**。
3. **幸いなことに**、怪我はなかった。

**近义辨析**
| | ことになる | ことにする | ことになっている |
|---|------------|------------|------------------|
| 谁决定 | 客观/外界 | 主观决定 | 规定/惯例 |

**真题提示**：看到 **驚いた／残念／幸い** → ことに；看到 **决定/规定/结果是** → ことになる。

### 副词（真题 **10** 次 · 2018.07、2018.12、2019.07、2019.12、2021.07、2021.12、2024.07、2024.12、2025.07）

**核心义**：N2 真题常单独考副词辨析，以下为高频项：

| 副词 | 义 | 例句 |
|------|-----|------|
| **いったい** | 到底、究竟 | **いったい**何が問題だ |
| **つい** | 不由得、无意中 | **つい**食べ過ぎた |
| **いつのまにか** | 不知不觉 | **いつのまにか**春になった |
| **まもなく** | 不久、眼看就要 | **まもなく**出発します |
| **かえって** | 反而 | 説明した**かえって**混乱した |
| **どうしても** | 务必/怎么也 | **どうしても**行きたい |
| **おそらく** | 恐怕、大概 | **おそらく**雨だろう |
| **一気に** | 一口气（单人） | **一気に**食べた |
| **一斉に** | 一齐（多人） | 皆**一斉に**立った |

**近义辨析**
- **一気に** vs **一斉に**：是否「みんな/皆」
- **いったい** vs **どうしても**：疑问 vs 意志
- **つい** vs **いつのまにか**：主观失手 vs 时间 unnoticed

**真题提示**：填空四选项全是副词时，看 **前后句逻辑**（转折→かえって；疑问→いったい；时间→まもなく/いつのまにか）。

### 〜だけ／きり／抜き（真题 **9** 次 · 2016.07、2018.07、2019.07、2020.12、2022.07、2024.07、2025.12）

**核心义**（三个限定表达，真题常混考）
- **だけ**：只、仅；**だけの**＋名：仅仅…的
- **きり／っきり**：自从…就再没…；只有…
- **抜き（で）**：去掉…、不用…、省略…

**接续**
- 名＋だけ（の）
- 名＋きり（っきり）
- 名＋抜き（で）

**用法详解**
- `朝食抜きで`：没吃早饭（省略某环节）
- `東京きり`：自从去了东京就……
- `見るだけのつもりで`：本打算只看看 → 常与「つい…てしまう」语序题联动
- `だけでなく`：不仅…而且…

**例句**
1. 今朝は寝坊して、朝食**抜きで**大学に来た。
2. 彼女に会った**きり**、連絡がない。
3. ちょっと**見るだけの**つもりで入った店で、つい買ってしまった。

**真题提示**：看到 **抜き／きり／だけ** 同时出现，抓句子语义：「不做某事」→抜き；「自从…后没再」→きり；「只/本打算只」→だけ。

### 目的・原因（真题 **9** 次 · 2017.12、2019.07、2021.07、2021.12、2023.12、2024.12）

**核心义**：表 **目的**、**原因/理由**、**结果归因** 的多种表达，N2 极高频混考。

**主要句型**

| 句型 | 义 | 接续 |
|------|-----|------|
| **ように** | 为了…（目的） | 动词辞书形/ない形＋ように |
| **ために** | 为了…/因为… | 名のために；动词辞书形＋ために |
| **おかげで** | 多亏…（好结果） | 原因＋おかげで |
| **せいで** | 都怪…（坏结果） | 原因＋せいで |
| **から／ので** | 因为… | 普通形＋から/ので |

**用法详解**
- `分かる**ように**説明する`：为了让人懂
- `雨**のせいで**試合中止`：都怪雨
- `先生**のおかげで**合格`：多亏了老师
- ために：名词/动词都可；**ために** 可表目的也可表原因，看上下文

**例句**
1. 健康**のために**運動している。（目的）
2. 事故**のせいで**電車が遅れた。（原因·负面）
3. 聞こえる**ように**大きな声で話した。

**真题提示**：**好结果** → おかげで；**坏结果** → せいで；**目的** → ように／ために；后接「说明/努力」→ ように。

### 补助动词（真题 **9** 次 · 2017.12、2018.07、2018.12、2020.12、2023.12、2024.07、2025.07）

**核心义**：接在 **て形** 后，补充动作的方式、意图、结果等。N2 常考：

| 补助 | 义 | 例 |
|------|-----|-----|
| **てみる** | 试着做 | 食べ**てみる** |
| **てしまう** | 做完/ unfortunately | 忘れ**てしまった** |
| **ておく** | 预先做好 | 予約し**ておく** |
| **てくる** | 开始做/来到现在 | 雨が降っ**てきた** |
| **ていく** | 继续/向未来 | これからも頑張っ**ていく** |
| **つもり（で）** | 打算/本以为 | 見る**つもりで** |
| **てほしい** | 希望别人做 | 来**てほしい** |
| **てあげる/もらう/くれる** | 授受 | 教え**てあげる** |

**语序题高频**：`ちょっと **見るつもりで** 服屋に入ったら、つい買ってしまった`

**真题提示**
- 「本打算只…却…」→ **つもりで** + **てしまう**
- 「希望对方…」→ **てほしい**（注意主语）
- 「预先…」→ **ておく**

### 〜ばかり（真题 **8** 次 · 2015.07、2016.07、2017.07、2018.12、2020.12、2024.07、2024.12）

**核心义**（多义，需看上下文）
1. **只、仅**（≈だけ，但语气稍重）
2. **几乎全是**（后面接名词）
3. **越来越…**（形容词/形容动词词干＋**ばかりだ**／**ばかり**）

**接续**
- 名詞＋ばかり
- 动词て形＋ばかり（いる）
- イ形/ナ形词干＋ばかり（だ）

**用法详解**
- `むしろ〜ばかり`：非但没有好转，反而越来越……（2015.07 第35题经典）
- `〜たばかり`：刚……（时间点，与「ばかりだ」趋势义不同）
- `〜ばかりか`：不仅……而且……

**例句**
1. 雨はやまず、むしろ**強くなるばかり**だった。
2. 彼女は文句**ばかり**言っている。
3. 日本**に来たばかり**で、まだ慣れない。

**近义辨析**
| | ばかり | だけ |
|---|--------|------|
| 只/仅 | ✓ | ✓ |
| 越来越 | ばかりだ | ✗ |
| 刚… | たばかり | たところ |

**真题提示**：题干有 **むしろ／一方で** → 倾向「越来越」；选项为形容词四种形态 → 选 **词干+ばかり** 或 **ばかりだ**。

### 引用・是否（真题 **7** 次 · 2018.07、2018.12、2021.12、2023.12、2024.12、2025.07）

**核心义**：引用、定义、是否判断。

**主要句型**
- **かどうか**：是否……（行く**かどうか**）
- **というと／といえば**：说到……；如果说是……
- **というのは**：所谓……是（定义）
- **というより**：与其说……不如说……
- **とは限らない**：不一定……

**例句**
1. 参加する**かどうか**まだ決めていない。
2. 日本**というと**、桜を思い浮かべる。
3. 彼**といえば**、昨日会ったばかりだ。

**真题提示**：`〜かどうか` 后接 **わからない／決めていない**；`というと` 后接 **典型联想**。

### 条件・义务（真题 **6** 次 · 2015.07、2020.12、2021.07、2022.07、2024.12）

**核心义**：条件、义务、禁止。

**主要句型**
| 句型 | 义 |
|------|-----|
| **なければならない** | 必须 |
| **なくてはいけない/ならない** | 必须（口语） |
| **ないと** | 必须/否则（口语） |
| **てはいけない** | 不许 |
| **てからでないと** | 必须先…才能… |
| **以上（は）** | 既然…就… |
| **べきだ** | 应该（道义） |

**例句**
1. 規則を守ら**なければならない**。
2. 約束した**以上は**守るべきだ。
3. ここでタバコを吸っ**てはいけない**。

**真题提示**：「必须做」→ なければならない；「既然…就…」→ 以上は；「禁止」→ てはいけない。

### 数量＋に（达到）（真题 **4** 次 · 2015.07、2015.12、2024.07、2025.12）

**核心义**：数量词后接助词 **に**，表示数量「达到」某一水平，与移动、达成类动词搭配。

**接续**：数量词（数字+量词）＋ **に** ＋ 上る／達する／及ぶ 等

**用法详解**
- 「に上る」= 达到（人数、金额、规模），书面、新闻常见
- 「に達する」= 达到（标准、数值）
- 助词对比：**で**=方式/原因；**を**=宾语；**も**=「也/竟有」强调数量之多

**例句**
1. 入場者数は1000万人**に上った**。（入场人数达到了1000万）
2. 売上高が昨年**に達した**。（销售额达到了去年水平）
3. 被害者は100人**を超えた**。（受害者超过了100人）← 超える前用「を」

**近义辨析**
| 助词 | 功能 | 典型动词 |
|------|------|----------|
| に | 达到某数量点 | 上る、達する |
| を | 越过/超过 | 超える |
| で | 方式、原因 | — |

**真题提示（2015.07 第33题）**：`1000万人（ ）上った` → 选 **に**。看到「数字+上る/達する」几乎固定 **に**。

### 〜もの（真题 **4** 次 · 2016.07、2017.07、2020.12、2023.12）

**核心义**
- **ものだ**：一般性道理（孩子就是活泼啊）
- **ものではない**：不应该（不做某事）

**33** [填空] **数量＋に（达到）**
- **要点**：数量词后接助词 **に**，表示数量「达到」某一水平，与移动、达成类动词搭配。
- **题干**：Y遊園地の昨年の入場者数は、1000万人（ ）上った。
- **选项**：1.に　2.で　3.を　4.も
- **例句**：入場者数は1000万人**に上った**。（入场人数达到了1000万）
- **做题**：真题提示（2015.07 第33题）：`1000万人（ ）上った` → 选 に。看到「数字+上る/達する」几乎固定 に。

**34** [填空] **〜をめぐって**
- **要点**：
- **题干**：鉄道会社と自治体による長期間の議論（ ）、新駅の建設が決定された。
- **选项**：1.をめぐり　2.を込めて　3.の末に　4.のことで

- **做题**：真题提示：选项常四者齐出（をめぐり／を込めて／の末に／のことで）。议论+最终决定 → の末に；围绕某议题 → をめぐって。
