# 雅思口语答题基本逻辑PART1

不管怎么问，**底层都是同一套**：

> **接住问题类型 → 直接答那一项 → 补原因/习惯 → 加一个具体细节**

下面按 **问法类型** 列逻辑；每类给 **3 句框架 + 例句**。

---

## 总公式（万能）

```
S1  直接回答问的那一点（别跑题）
S2  原因 / 习惯 / 频率 / 对比
S3  具体细节（人/事/物/时间/地点）
```

**时长**：15–30 秒 | **句数**：2–4 句

---

## 一、喜好类

### 1. `Do you like...?` / `Do you enjoy...?`

**逻辑**：态度 → 为什么 → 具体

```
S1  Yes/No + especially/mainly...
S2  because / I usually...
S3  Recently... / For example...
```

> **Do you like reading?**  
> Yes, **especially** non-fiction. I usually read before bed **because** it helps me unwind. **Recently**, I've been into psychology books.

---

### 2. `What's your favourite...?`

**逻辑**：点名 favourite → 为什么是它 → 一个具体场景

```
S1  My favourite is... / I'd go with...
S2  The main reason is...
S3  I often... when... / Last time...
```

> **What's your favourite season?**  
> **I'd say autumn.** The weather's comfortable and the scenery's beautiful. **I especially enjoy** taking walks in the park around October.

---

### 3. `Do you prefer A or B?`

**逻辑**：二选一（别两边讨好）→ 原因 → 偶尔例外（可选）

```
S1  I'd prefer A / I'm more of an A person
S2  because...
S3  Though sometimes I...（让步，加分）
```

> **Do you prefer tea or coffee?**  
> **Definitely coffee**, especially in the morning **because** it wakes me up. **Though** on hot days, I might go for iced tea instead.

---

## 二、频率 / 时间类

### 4. `How often do you...?`

**逻辑**：频率词直接答 → 什么时候 → 具体最近一次

```
S1  频率（every day / a couple of times a week / rarely）
S2  通常什么时候/什么场合
S3  上个具体例子
```

> **How often do you exercise?**  
> **About three times a week.** I usually go jogging after work on weekdays. **Just yesterday**, I ran along the river for half an hour.

---

### 5. `When do you usually...?`

**逻辑**：时间点 → 为什么选这时 → 具体习惯

```
S1  时间（in the morning / before bed / at weekends）
S2  because / it fits my schedule
S3  补充细节
```

> **When do you usually study?**  
> **Mostly in the evening**, after dinner, **because** that's when I'm least distracted. **I normally** study at my desk for about two hours.

---

### 6. `How long do you spend...?` / `How much time...?`

**逻辑**：时长/数量 → 用来干什么 → 感受/原因

```
S1  数字（about 2 hours / not that much）
S2  doing what / on what
S3  why / how I feel about it
```

> **How long do you spend on your phone?**  
> **Probably 3–4 hours a day**, mostly on social media and messaging. **I know it's a bit much**, but it's how I stay in touch with friends.

---

### 7. `How long have you been...?`（现在完成）

**逻辑**：多久了 → 为什么开始 → 现在怎样

```
S1  for + 时间段（for about 5 years）
S2  I started because...
S3  Now I... / Nowadays...
```

> **How long have you been learning English?**  
> **For roughly ten years**, since middle school. **I started because** it was compulsory, but **now I actually enjoy** using it to watch documentaries.

---

## 三、地点 / 人物类

### 8. `Where do you...?`

**逻辑**：地点 → 为什么选那里 → 具体描述

```
S1  地点
S2  because / it's convenient / I like the atmosphere
S3  一个小细节
```

> **Where do you usually shop?**  
> **Mostly at a mall near my home.** It's within walking distance, which is super convenient. **There's a supermarket** on the ground floor where I buy groceries.

---

### 9. `Who do you usually... with?`

**逻辑**：谁 → 为什么跟这人 → 一起做什么

```
S1  人物
S2  because / we share the same interest
S3  具体活动
```

> **Who do you usually hang out with?**  
> **Mainly my college roommate.** We get along really well and have similar tastes. **We often** grab dinner and watch films together on weekends.

---

## 四、是否 / 有无类

### 10. `Do you have...?` / `Is there...?` / `Are there...?`

**逻辑**：有/没有 → 什么样 → 用途/感受

```
S1  Yes/No + 具体有什么
S2  特点/位置/情况
S3  对你意味着什么
```

> **Do you have a garden?**  
> **Not really a garden**, but we have a small balcony with a few plants. **My mum grows** tomatoes and herbs there. **It's nice** to have some greenery at home.

---

### 11. `Did you... when you were a child?` / `...as a child?`

**逻辑**：过去（过去时）→ 现在对比 → 为什么变了/没变

```
S1  小时候怎样（Yes, I used to...）
S2  Now... / These days...
S3  原因/感受
```

> **Did you like sports as a child?**  
> **Yes, I was quite active.** I **used to** play basketball every weekend with classmates. **These days** I'm busier, so I only exercise occasionally.

---

## 五、变化类

### 12. `Has ... changed?` / `How has ... changed?`

**逻辑**：变了/没变 → 怎么变 → 你的感受

```
S1  总体判断（Yes, quite a lot / Not really）
S2  具体变化（used to be... but now...）
S3  个人感受（I think it's...）
```

> **Has your hometown changed much?**  
> **Yes, dramatically.** It **used to be** a quiet small town, **but now** there are high-rises and a metro line. **Overall**, I think it's more convenient, though less peaceful.

---

### 13. `Do you think ... will change?`（将来）

**逻辑**：会/不会 → 理由 → 你希望怎样（可选）

```
S1  I think it will / probably not
S2  because...
S3  Personally, I'd like to see...
```

> **Do you think your neighbourhood will change?**  
> **Probably yes.** With all the new developments nearby, more facilities might be built. **I'd hope** they keep some green spaces though.

---

## 六、程度 / 评价类

### 14. `Is ... important to you?` / `How important is...?`

**逻辑**：程度 → 为什么 → 生活中的体现

```
S1  程度（quite / fairly / not really）
S2  because...
S3  你怎么做的/例子
```

> **Is money important to you?**  
> **Fairly important**, but not the top priority. **I need it** for a decent living standard, but **I value** work-life balance more.

---

### 15. `Are you good at...?`

**逻辑**：诚实评价 → 举例证明/反驳 → 是否在提高

```
S1  程度（I'd say I'm decent / not really）
S2  例子
S3  I'm trying to improve...（可选）
```

> **Are you good at cooking?**  
> **I'd say I'm average.** I can handle simple dishes like fried rice and pasta. **Recently**, I've been learning from online videos to get better.

---

### 16. `What do you think of...?` / `How do you feel about...?`

**逻辑**：评价 → 理由 → 个人经历

```
S1  态度（positive/negative/mixed）
S2  because...
S3  For me personally...
```

> **How do you feel about social media?**  
> **Mixed feelings, to be honest.** It's great for staying connected, **but** it can be a huge time-waster. **Personally**, I try to limit it to 30 minutes a day.

---

## 七、行为 / 习惯类

### 17. `What do you usually do...?` / `What do you do in...?`

**逻辑**：典型活动 → 频率/顺序 → 一个具体细节

```
S1  主要做什么
S2  when/how often
S3  补充一个细节
```

> **What do you usually do on weekends?**  
> **I tend to sleep in** and then meet friends for brunch. **In the afternoon**, I might go to the gym or catch up on chores. **Last Saturday**, we tried a new café downtown.

---

### 18. `Would you like to...?` / `Do you want to...?`（意愿）

**逻辑**：想/不想 → 原因 → 有没有计划

```
S1  Yes/Not really/Maybe in the future
S2  because...
S3  I'm planning to... / I haven't thought about it yet
```

> **Would you like to live abroad?**  
> **Yes, actually.** I'd love to experience a different culture and improve my independence. **I'm considering** studying in the UK next year.

---

## 八、群体 / 文化类

### 19. `Do people in your country...?`

**逻辑**：普遍情况 → 你个人是否一样 → 简短原因

```
S1  Generally yes/no
S2  In my case...
S3  I think it's because...
```

> **Do people in your country like tea?**  
> **Yes, definitely** — tea culture is huge here. **In my family**, we drink tea after every meal. **I think it's** partly about tradition and hospitality.

---

### 20. `Is it common to... in your country?`

**逻辑**：是否普遍 → 举例 → 趋势变化（可选）

```
S1  Quite common / Not that common
S2  For example...
S3  Nowadays...（可选）
```

> **Is it common to work from home in your country?**  
> **Much more common than before**, especially after the pandemic. **Many companies** now offer flexible schedules. **In my case**, I work from home twice a week.

---

## 九、特殊问法速查

| 问法关键词               | 第一句必须答什么 | 时态注意               |
| ------------------------ | ---------------- | ---------------------- |
| **Do/Does**              | Yes/No + 偏好    | 一般现在               |
| **Did**                  | 过去事实         | **过去时**             |
| **Have you ever**        | Yes/No + 经历    | **现在完成**           |
| **How often**            | 频率词           | 一般现在               |
| **When**                 | 时间点           | 看语境                 |
| **Where**                | 地点             | 一般现在               |
| **Who**                  | 人物             | 一般现在               |
| **What kind/type**       | 具体类别         | 一般现在               |
| **Why**                  | 原因             | because/since          |
| **How**                  | 方式/程度        | 看具体问题             |
| **Would you**            | 意愿/假设        | would/could            |
| **Has/Have ... changed** | 变没变           | **对比 used to / now** |
| **Prefer**               | 二选一           | 别两边都要             |
| **Favourite**            | 一个最爱         | 要具体                 |

## 十、一张图记全（考场 3 秒用）

```
听到问题
    │
    ├─ 问态度？     → 直接表态 + because + 例子
    ├─ 问频率？     → 频率词 + 什么时候 + 上次...
    ├─ 问时间？     → 时间点 + 为什么 + 习惯
    ├─ 问地点/人？  → 地点/人 + 原因 + 细节
    ├─ 问有没有？   → 有/无 + 什么样 + 感受
    ├─ 问过去？     → used to + 现在对比
    ├─ 问变化？     → 变没变 + used to vs now
    ├─ 问将来？     → will/would + 原因
    ├─ 问程度？     → quite/fairly + 理由 + 体现
    └─ 二选一？     → 选一个 + 原因 + though...
```

## 最后：7 分 Part 1 的「所有问法」共性

不管哪种问法，**7 分逻辑永远不变**：

1. **第一句答在问题上**（问什么答什么，别绕）
2. **第二句给原因或习惯**（because / usually / I tend to）
3. **第三句落地到具体**（人/事/物/时间，带一个名词）
4. **至少一句复杂结构**（because / although / I've been / used to）
5. **15–30 秒收住**（别抢 Part 2 的戏）

你要的话，我可以把上面 20 类做成 **一页 A4 背诵表**（只有英文框架句，无例句），方便你考前扫一眼。
