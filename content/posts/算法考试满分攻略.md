## 题型1：增长量级与代码框架（15分）

### 必背考点

- **渐近分析**：只保留最高次项；`k₁n² + k₂n + k₃ ~ n²`
- **O / Ω / Θ**：O 最坏上界，Ω 最好下界，Θ 紧确界
- **主定理**：`T(n) = aT(n/b) + f(n)`，比较 `f(n)` 与 `n^(log_b a)`
- **常见复杂度对应代码**：

| 增长量级 | 典型代码框架 |
|----------|--------------|
| **N** | `for (i = 0; i < N; i++) { ... }` |
| **N lg N** | 外 N 内 log：`for (i=0; i<N; i++) for (j=1; j<N; j*=2)` |
| **N²** | 双重循环：`for (i=0; i<N; i++) for (j=0; j<N; j++)` |

### 2021 标准答案

```c
// N — 题目已给出
for (int i = 0; i < N; i++) { ... }

// N lg N
for (int i = 0; i < N; i++)
    for (int j = 1; j < N; j = 2*j) { ... }

// N²
for (int i = 0; i < N; i++)
    for (int j = 0; j < N; j++) { ... }
```

### 抢分技巧

- 看到 `j *= 2` 或 `j /= 2` → **log N** 层
- 两层都到 N → **N²**
- 一层 N 一层 log → **N lg N**

## 题型2：Union-Find 并查集（10分）

### 必背考点

- **quick-union**：`id[p] = q`，小树挂大树（无优化）
- **weighted quick-union**：小树挂大树 + **size[]** 维护
- **find**：沿 `id[]` 找根
- 每处理一对 **union 后画出 id[] 森林**，直到题目指定两点连通

### 2021 例题过程

**输入序列**：`0-6  6-1  4-5  6-4  2-4  6-3`，直到 **0 与 5 连通**

#### Quick-Union（id[p] = q 风格）

| 步骤 | 操作 | id[] |
|------|------|------|
| 初态 | — | [0,1,2,3,4,5,6] |
| 0-6 | id[0]=6 | [6,1,2,3,4,5,6] |
| 6-1 | id[6]=1 | [6,1,2,3,4,5,1] |
| 4-5 | id[4]=5 | [6,1,2,3,5,5,1] |
| 6-4 | id[1]=5 | [6,5,2,3,5,5,1] |
| 2-4 | id[2]=5 | [6,5,5,3,5,5,1] |
| 6-3 | id[5]=3 | [6,5,5,3,3,3,1] ✓ |

此时 `find(0) = find(5) = 3`，停止。

#### Weighted Quick-Union

| 步骤 | 操作 | id[] |
|------|------|------|
| 0-6 | 1→6 | [6,6,2,3,4,5,6] |
| 6-1 | 已连通 | 同上 |
| 4-5 | 4→5 | [6,6,2,3,5,5,6] |
| 6-4 | 5→6 | [6,6,2,3,5,6,6] |
| 2-4 | 2→6 | [6,6,6,3,5,6,6] |
| 6-3 | 3→6 | [6,6,6,6,5,6,6] ✓ |

### 答题模板

1. 画 7 个圈，标 0–6
2. 每步 union 后更新箭头（parent 指向）
3. 标注 size（加权版）
4. 每步检查 `find(0) == find(5)?`

## 题型3：排序（20分）

### (1) 归并排序 merge 填空（10分）

**必背四行**（Sedgewick 风格）：

```java
if       (i > mid)               a[k] = aux[j++];
else if  (j > hi)               a[k] = aux[i++];
else if  (less(aux[j], aux[i])) a[k] = aux[j++];
else                            a[k] = aux[i++];
```

**考点**：左半用完取右、右半用完取左、比较取小、相等取左（稳定）。

### (2) 快排 partition 追踪（10分）

数组：`E D S Y F U E S`，通常 **首元素作 pivot**（v = E）

**Hoare 双指针模板**：

```
i = lo, j = hi + 1, v = a[lo]
loop:
  while less(a[++i], v)   // i 右移
  while less(v, a[--j])   // j 左移
  if i >= j break
  swap(a[i], a[j])
swap(a[lo], a[j])
return j
```

**答题要求**：逐步写出 i、j 位置、交换后数组、最终 pivot 位置。

**课件要点（2.3）**：

- 归并：`T(n) = 2T(n/2) + O(n)` → **O(n lg n)**
- 快排：分治时多干活（partition），合并时不用 merge
- 归并稳定，快排不稳定

## 题型4：BST 最好/最坏情况（10分）

### 考点

- 按给定顺序 **逐个 insert** 画树
- **最坏**：插入顺序等于中序遍历（有序）→ 退化成链
- **最好**：每次接近中位数 → 近似平衡

### 2021：键 `R E S P O N D`，给定插入顺序

**按题目顺序插入（实际树形）**：

```
        R
       / \
      E   S
         /
        P
       /
      O
     /
    N
   /
  D
```

**最坏情况**：按字母序 `D E N O P R S` 插入 → 全右链（或全左链）

**最好情况**：先插中间键（如 **O** 或 **P**），再分左右，例如 `O, E, S, N, P, R, D` → 较平衡

### 抢分

- 最坏：**画一条斜链**
- 最好：**画近似满二叉树**
- 标注插入顺序

## 题型6：最短路径 Dijkstra（15分）

### 有向图（2021 原题）

| 边 | 权 |
|----|-----|
| a→b | 1 |
| a→d | 5 |
| b→c | 1 |
| c→a | 1 |
| c→f | 4 |
| d→f | 2 |
| d→g | 1 |
| e→f | 1 |
| e→g | 4 |
| f→e | 1 |
| f→g | 3 |

### (1) 最终 distTo / edgeTo（10分）

从 **a** 出发：

| vertex | distTo | edgeTo |
|--------|--------|--------|
| a | 0 | null |
| b | 1 | a |
| c | 2 | b |
| d | 5 | a |
| e | 7 | f |
| f | 6 | c |
| g | 6 | d |

### (2) distTo[e] 出现过的值（5分）

e 被松弛时：**∞ → 7**（在处理 **f** 时，`dist[f] + 1 = 7`）

| distTo[e] | edgeTo[e] |
|-----------|-----------|
| ∞ | null |
| 7 | f |

### 算法选择（课件 3.8）

| 场景 | 算法 | 复杂度 |
|------|------|--------|
| 无负权边 | **Dijkstra** | O(E log V) |
| 有负权边、无负环 | **Bellman-Ford** | O(VE)，\|V\|-1 轮 |
| 全源最短路 | **Floyd-Warshall** | O(V³) |

**Dijkstra 核心**：非负权 → 每次取 **dist 最小** 的未确定顶点松弛。

## 题型7：算法设计（15分）

### 2021 题目

N 个 `'a'~'z'` 字符，**O(N) 预处理**，**O(1) 查询**「≥ β 的字符个数」。

### 标准答案

**预处理**：

```text
1. cnt[26] = 各字符频次
2. suf[i] = 字符 >= ('a'+i) 的个数
   for i = 25 downto 0:
       suf[i] = suf[i+1] + cnt[i]   // suf[26] = 0
```

**查询**：`return suf[β - 'a']`

**评分点**：正确性、O(N) 预处理、O(1) 查询、表述清晰。

### 同类变形

- 「≤ β 的个数」→ 前缀和 `pre[i]`
- 「第 k 小字符」→ 前缀和 + 二分

## 全章考点地图（按 PPT 章节）

```
第1章 基础
├── 最大子数组：暴力 O(n³) → 改进 O(n²) → 分治 O(n log n) → Kadane O(n)
├── 渐近表示：O, Ω, Θ
└── 递归时间：代入法、主定理

第2章 分治
├── 模板：分解 → 递归 → 合并
├── 排序：归并 O(n log n)、快排 O(n log n) 平均
├── 堆：BuildMaxHeap O(n)、MaxHeapify、优先队列
├── 选择：QuickSelect、中位数
└── 最大子数组分治：跨中点 + 左 + 右

第3章 DP / 贪心
├── DP 四步：最优子结构 → 定义值 → 自底向上 → 构造解
├── 经典：装配线、矩阵链乘、LCS、0/1 背包、活动选择
├── 贪心：活动选择(按结束时间)、分数背包(按价值密度)
├── 最短路径：Dijkstra / Bellman-Ford / Floyd
└── 注意：最大子数组 I 型不用子问题最优解；LCS/背包必 DP

第4章 难解问题
├── 不能分治：子集和、N 皇后、TSP 类
├── 回溯：DFS + 约束 + 限界函数
└── NP 完全：判定问题、归约（了解概念）
```

## 各题满分要点

### 905 归并排序

```c
#include <stdio.h>
#include <stdlib.h>

#define INF 2147483647

void Merge(int a[], int p, int q, int r)
{
    int n1 = q - p + 1, n2 = r - q;
    int *L = (int *)malloc((n1 + 1) * sizeof(int));
    int *R = (int *)malloc((n2 + 1) * sizeof(int));
    int i, j, k;

    for (i = 0; i < n1; i++) L[i] = a[p + i];
    for (j = 0; j < n2; j++) R[j] = a[q + 1 + j];
    L[n1] = INF;
    R[n2] = INF;
    i = 0;
    j = 0;
    for (k = p; k <= r; k++) {
        if (L[i] <= R[j]) { a[k] = L[i]; i++; }
        else              { a[k] = R[j]; j++; }
    }
    free(L);
    free(R);
}

void MergeSort(int a[], int p, int r)
{
    if (p < r) {
        int q = (p + r) / 2;
        MergeSort(a, p, q);
        MergeSort(a, q + 1, r);
        Merge(a, p, q, r);
    }
}
```

**易错点**：

- 临时数组 `L`、`R` 记得 `malloc` 和 `free`
- 哨兵 `L[n1] = INF` 不能少
- `MergeSort` 终止条件 `p < r`，不是 `p <= r`
- 输出：空格分隔，末尾换行

### 906 构造大顶堆

```c
#include <stdio.h>

void MaxHeapify(int a[], int heap_size, int root)
{
    while (1) {
        int left = 2 * root + 1;
        int right = 2 * root + 2;
        int largest = root;

        if (left < heap_size && a[left] > a[largest])
            largest = left;
        if (right < heap_size && a[right] > a[largest])
            largest = right;
        if (largest == root)
            return;
        {
            int temp = a[root];
            a[root] = a[largest];
            a[largest] = temp;
            root = largest;
        }
    }
}

void BuildMaxHeap(int a[], int n)
{
    int i;
    for (i = n / 2 - 1; i >= 0; i--)
        MaxHeapify(a, n, i);
}
```

**易错点**：

- 孩子下标：`2*root+1` 和 `2*root+2`（数组从 0 开始）
- 比较条件：`left < heap_size` 不是 `<=`
- 交换后 `root = largest` 继续下沉，不要直接 `return`
- 建堆从 `n/2 - 1` 开始到 0

### 908 青蛙爬楼梯

```c
#include <stdio.h>
#include <string.h>

long long memo[45];

long long FrogJump(int x)
{
    if (x == 0) return 1;
    if (x == 1) return 1;
    if (x == 2) return 2;
    if (memo[x] != -1)
        return memo[x];
    memo[x] = FrogJump(x - 1) + FrogJump(x - 2);
    return memo[x];
}

int main(void)
{
    int x;
    memset(memo, -1, sizeof(memo));
    scanf("%d", &x);
    printf("%lld\n", FrogJump(x));
    return 0;
}
```

**易错点**：

- 返回值用 `long long`，输出用 `%lld`
- `memset(memo, -1, sizeof(memo))` 在调用前执行
- `memo` 定义为全局数组，递归才能访问

### 912 装配线调度（课件 3.1 原题）

```c
#include <stdio.h>

int min_int(int a, int b) { return a < b ? a : b; }

int main(void)
{
    int n, j;
    int a[2][2005], t[2][2005], e[2], x[2], f[2][2005];

    scanf("%d", &n);
    for (j = 0; j < n; j++) scanf("%d", &a[0][j]);
    for (j = 0; j < n; j++) scanf("%d", &a[1][j]);
    for (j = 0; j < n - 1; j++) scanf("%d", &t[0][j]);
    for (j = 0; j < n - 1; j++) scanf("%d", &t[1][j]);
    scanf("%d %d", &e[0], &e[1]);
    scanf("%d %d", &x[0], &x[1]);

    f[0][0] = e[0] + a[0][0];
    f[1][0] = e[1] + a[1][0];
    for (j = 1; j < n; j++) {
        f[0][j] = min_int(f[0][j - 1], f[1][j - 1] + t[1][j - 1]) + a[0][j];
        f[1][j] = min_int(f[1][j - 1], f[0][j - 1] + t[0][j - 1]) + a[1][j];
    }
    printf("%d\n", min_int(f[0][n - 1] + x[0], f[1][n - 1] + x[1]));
    return 0;
}
```

**读入顺序**：n → a[0][] → a[1][] → t[0][] → t[1][] → e[0],e[1] → x[0],x[1]

**易错点**：t 数组只有 n-1 个；最后要加下线时间 x[0]、x[1]；C 里没有内置 `min`，需自写函数

### 916 最长公共子序列 LCS

```c
#include <stdio.h>
#include <string.h>

#define MAXL 2005

static int dp[MAXL][MAXL];

int max_int(int a, int b) { return a > b ? a : b; }

int main(void)
{
    char X[MAXL], Y[MAXL];
    int m, n, i, j;

    scanf("%s", X);
    scanf("%s", Y);
    m = (int)strlen(X);
    n = (int)strlen(Y);

    for (i = 1; i <= m; i++) {
        for (j = 1; j <= n; j++) {
            if (X[i - 1] == Y[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max_int(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    printf("%d\n", dp[m][n]);
    return 0;
}
```

**易错点**：

- `static int dp[2005][2005]` 放全局区，否则段错误
- 字符串下标从 0 开始，`X[i-1]` 对应 `dp[i]`
- dp 下标从 1 开始，0 行 0 列默认为 0（`static` 自动初始化为 0）

### 917 最长回文子序列 LPS

```c
#include <stdio.h>
#include <string.h>

#define MAXL 4005

static short dp[MAXL][MAXL];

int max_int(int a, int b) { return a > b ? a : b; }

int main(void)
{
    char S[MAXL];
    int n, i, j, len;

    scanf("%s", S);
    n = (int)strlen(S);

    for (i = 0; i < n; i++)
        dp[i][i] = 1;

    for (len = 2; len <= n; len++) {
        for (i = 0; i <= n - len; i++) {
            j = i + len - 1;
            if (S[i] == S[j]) {
                if (len == 2)
                    dp[i][j] = 2;
                else
                    dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = max_int(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    printf("%d\n", dp[0][n - 1]);
    return 0;
}
```

**易错点**：

- 填表顺序必须是**按子串长度 len**，不是行优先
- `dp` 用 `short` 可省一半空间（n=4000 时约 16MB）
- 长度 2 且首尾相同时特判 `dp[i][j] = 2`
- 结果在 `dp[0][n-1]`

### 918 分数背包

```c
#include <stdio.h>

int main(void)
{
    int n, W, i;
    int v[1005], w[1005];
    int remaining;
    double max_value = 0.0;

    scanf("%d %d", &n, &W);
    for (i = 0; i < n; i++) scanf("%d", &v[i]);
    for (i = 0; i < n; i++) scanf("%d", &w[i]);

    remaining = W;
    for (i = 0; i < n && remaining > 0; i++) {
        if (w[i] <= remaining) {
            max_value += v[i];
            remaining -= w[i];
        } else {
            max_value += (double)v[i] * remaining / w[i];
            remaining = 0;
        }
    }
    printf("%.2f\n", max_value);
    return 0;
}
```

**易错点**：

- 输出格式 `%.2f`，保留两位小数
- `max_value` 用 `double`，部分装载时 `(double)v[i] * remaining / w[i]`
- 循环条件加 `remaining > 0`
- 不需要排序，题目已按单位价值排好
